一个安装包、一个左侧 **CodeBuddy** 统一配置入口，内置 **国内版（`codebuddy-cli-cn`）** 与 **国际版（`codebuddy-cli-intl`）** 两个完全隔离的官方 CLI 提供方。DSH 继续管理会话与业务工具，本插件仅负责通过本地官方 CLI 调度模型与同步目录。

## 核心功能

- **连接配置**：一键检测与安装官方 CLI、展示可执行文件路径与版本、即时生效的功能开关（客户端标识覆盖与审计回显、脱敏请求样本采集、图片 Base64 内联、额度耗尽自动换号），以及可折叠的高级连接参数（基于已启用模型的默认模型/推理强度联动选择、默认 5 分钟超时与并发排队控制）。
- **模型目录**：每 15 分钟自动同步官方模型与积分倍率，支持按「全部 / 已启用 / 已停用」与能力标签（图片 / 推理 / ≤1×）筛选、搜索排序与批量启停；详见[工具适配范围](docs/cn/工具适配范围.md)。
- **多账号管理**：双栏账号概览与多账号隔离环境（Windows 官方 CLI 2.174.0 及以上，支持 npm 版 `codebuddy.cmd` 与官方 `codebuddy.exe`），实时展示剩余积分、渐变进度条与资源包到期提醒，支持额度耗尽自动切号；详见[多账号使用指南](docs/intl/多账号使用指南.md)。
- **Token 用量**：独立 6 卡片可视化仪表盘，涵盖 6 格用量总览与缓存命中率环形图、分模型堆叠构成图、最近 24 次调用趋势（耗时 / Token 切换）、失败原因分布、分模型明细表与 CSV 导出，超时卡片直接附带请求体量提示。
- **日志查看**：默认自动加载展开的结构化日志时间线，支持按状态（全部 / 失败 / 取消 / 图片卸载）与关键词筛选、原始 JSON 切换、一键导出普通/详细日志与脱敏样本；所有日志仅存本机，不含自动上传。

## 区域隔离与边界

- 国内版与国际版分别维护独立的子进程环境、模型目录、用量统计、诊断日志与取消状态，页面顶部切换区域仅改变当前配置视图，不影响会话内选定的提供方。
- 文本请求封装上限 12 MiB，国内最终输入上限 20 MiB，国际图片流输入上限 24 MiB。
- 登录与额度由官方 CLI 与官方站点处理；本插件不提供共享账号、转发服务器或额度转售。
